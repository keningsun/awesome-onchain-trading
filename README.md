## Trading Workflows

### 1. Smart Money Following Strategy

**监控阶段**

- 使用 Nansen/Lookonchain/Spot On Chain 监控知名投资者和鲸鱼钱包
- 配置 DeBank/Zerion 设置钱包地址监控
- 使用 Wallet Watcher 设置交易提醒

**分析决策**

- 通过 Bubblemaps/Arkham 分析目标代币的持仓分布
- 使用 Token Sniffer/Go Plus 进行合约安全检查
- 通过 Dune/Token Terminal 分析项目基本面

**执行交易**

- 使用 1inch/CowSwap 等 DEX 聚合器获得最佳价格
- 通过 Flashbots Protect 防止 MEV 攻击
- 用 Safe 钱包进行大额交易保护

### 2. Memecoin Trading Strategy

**监控阶段**

- 使用 GemFinder/Maestro 发现新代币
- 通过 DexTools/DexGuru 监控流动性变化

**分析决策**

- 使用 Holderscan 分析持币地址
- 通过 Crypto Sentiment 评估市场情绪
- 用 Eigenphi 分析套利空间

**执行交易**

- 使用 Unibot/Banana Gun 进行快速狙击
- 通过 Gas.watch 优化 Gas 费用
- 配置 Trading Lab 自动交易策略

### 3. DeFi Yield Strategy

### 4. Arbitrage Strategy

## Best Practices

1. 风险控制

   - 使用多签钱包管理资金
   - 每笔交易前进行合约安全检查
   - 设置止损和资金管理策略

2. 工具组合

   - 至少使用 2-3 个工具交叉验证信号
   - 配置多个预警通道保证及时性
   - 准备备用工具防止主要工具失效

3. 成本优化
   - 使用 DEX 聚合器获得最佳价格
   - 通过 Gas 工具优化交易成本
   - 选择合适的订阅计划降低工具成本
